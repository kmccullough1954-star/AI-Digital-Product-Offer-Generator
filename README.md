## Getting Started

### Prerequisites

- Python 3.8 or higher
- OpenAI API key (optional, for AI-powered generation)

### Installation

1. Clone this repository:
```bash
git clone https://github.com/kmccullough1954-star/AI-Digital-Product-Offer-Generator.git
cd AI-Digital-Product-Offer-Generator
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Set up your OpenAI API key (optional):
```bash
export OPENAI_API_KEY='your-api-key-here'
```

### Usage

Run the generator:
```bash
python generate_offer.py
```

Follow the interactive prompts to:
1. Enter your product idea
2. Specify your niche or industry
3. Define your target audience (optional)
4. Choose a monetization model

The generator will create a comprehensive digital product offer including:
- Product name and description
- Target audience profile
- Unique value proposition
- Product angle and positioning
- Pricing strategy
- Marketing copy templates
- Launch checklist
